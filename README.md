# iMusic — مشغل موسيقى عملي يعمل دون اتصال

مشغّل موسيقى عربي (RTL) يعمل كتطبيق ويب تثبيتي (PWA) كامل العمل دون إنترنت، مبني بـ HTML/CSS/JS خالص بدون أي مكتبات خارجية.

## المزايا

- **يعمل دون اتصال تماماً**: أغانيك تُخزن داخل جهازك (IndexedDB) — لا ترفعات لأي سيرفر.
- **قوائم تشغيل**: إنشاء قوائم، إضافة أغانٍ، إزالة، وإعادة ترتيب بالسحب وبالأسهم.
- **تشغيل بالسياق**: يعرف يشتغل من «المكتبة الكاملة» أو من أي قائمة، ويستمر بعد إعادة فتح التطبيق بآخر أغنية وموضع.
- **عشوائي وتكرار**: تكرار الكل، تكرار الأغنية (بشارة)، وخلط ترتيب العرض دون كسر سياق القائمة.
- **شاشة تشغيل كاملة**: غلاف مولّد لكل أغنية، شريط تقدم قابل للسحب، صوت وكتم.
- **تحكم النظام (MediaSession)**: أزرار سماعة البلوتوث/السيارة وشاشة القفل تعمل مباشرة، مع أسماء وأغلفة.
- **تثبيت كتطبيق**: زر «تثبيت التطبيق» يفتح التثبيت كتطبيق مستقل (يشبه محلياً).
- **وضع تحديد**: تحديد أغانٍ متعددة لإضافتها لقائمة أو حذفها دفعة واحدة (مع تأكيد).
- **مظهرين**: داكن وأناري، ويتذكر اختيارك.
- لغة عربية RTL بالكامل، مع تخطيط عمودي أفقي (لاندسكيب) لشاشة التشغيل.
- لا يطلب أي أذونات. لا إعلانات. لا تتبع.

## التشغيل محلياً

```bash
python dev/server.py 8090 .
```

ثم افتح `http://127.0.0.1:8090/` — بدون إعدادات إضافية.

> ملاحظة مهمة أثناء التطوير: استخدم `http://127.0.0.1:8090/?nosew` لتفعيل سلوك «بدون Service Worker» كي لا يخدم الكاش ملفات قديمة بعد تعديلات الكود.

## التثبيت من الرابط (جهازك الآخر)

1. افتح الرابط في Chrome (هاتف/تاب/حاسوب).
2. انقر زر **«تثبيت التطبيق»** أعلى الشاشة (أو أيقونة التثبيت في شريط العنوان).
3. يظهر التطبيق كأيقونة مستقلة يعمل بملء الشاشة وبلا شعارات متصفح.

## حفظ أغانيك

- أغانيك **تحفظ محلياً داخل المتصفح/التطبيق** على هذا الجهاز فقط.
- **مسح بيانات الموقع من إعدادات Chrome سيحذف جميع الأغاني نهائياً.**
- النقل بين الأجهزة: أعد إضافة الملفات (زر «إضافة أغانٍ») من كل جهاز — لا نرفع أي شيء.

## النشر

يُنشر على GitHub Pages من فرع `main` جذر المستودع (ملفات الجذر + مجلد `icons/`). بعد أول نشر، أي تعديل لاحق يعكسه المستخدمون عند إعادة التحميل عبر شريط «يوجد تحديث» وترقيم نسخة الـ `sw.js` (`VERSION = 'imusic-v1.0.0'`).

## الملفات

```
index.html            — هيكل التطبيق + أيقونات SVG
styles.css            — التنسيق (داكن/نهاري، RTL، لاندسكيب)
app.js                — كل المنطق (قاعدة بيانات، تشغيل، قوائم، تثبيت، تحديث)
sw.js                 — Service Worker (كاش أول، تحديث بالمزامنة)
manifest.webmanifest  — وصف التطبيق التثبيتي
icons/                — الأيقونات (SVG مصدر + PNG مولّدة)
dev/                  — أدوات تطوير (توليد أيقونات/أصوات تجربية وسيرفر بلا كاش)
```

## أذونات وخصوصية

- التطبيق لا يطلب أي أذونات ولا يحتاج أي حسابات.
- البيانات كلها أيضًا: أغانيك بقاعدة IndexedDB، والإعدادات في `localStorage` (`imusic-prefs`).
