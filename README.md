# iMusic — مشغل موسيقى عملي يعمل دون اتصال

مشغّل موسيقى عربي (RTL) يعمل كتطبيق ويب تثبيتي (PWA) كامل العمل دون إنترنت، مبني بـ HTML/CSS/JS خالص بدون أي مكتبات خارجية.

## المزايا

- **يعمل دون اتصال تماماً**: أغانيك تُخزن داخل جهازك (IndexedDB) — لا ترفعات لأي سيرفر.
- **صور الأغاني الحقيقية**: يقرأ الغلاف المدمج من ملفات MP3 (ID3v2) و M4A/MP4 و FLAC و OGG تلقائياً عند الإضافة، ويولّد غلافاً أنيقاً للأغاني بلا صورة.
- **إعادة تسمية الأغاني**: من قائمة خيارات الأغنية — يتحدث الاسم فوراً في المكتبة والقوائم وشاشة التشغيل وشاشة القفل.
- **عدّاد الاستماع + الترتيب**: يظهر عدد مرات تشغيل كل أغنية، مع ترتيب حسب الأحدث إضافة أو أبجدياً أو الأكثر تشغيلاً — في المكتبة وداخل قوائم التشغيل، ويسير التشغيل على الترتيب المعروض.
- **خلفيات متحركة** (من الإعدادات): «مجرة ونجوم» بنجوم متلألئة وشهب متساقطة (وتتحول لسماء نهار بشمس مشعة وغيم في الوضع الفاتح)، و«موجة صوتية» بخط يتفاعل مع ارتفاع الصوت وانخفاضه، و«أعمدة صوتية» بأعمدة مرآة ترقص مع نغمة الأغاني — مع ستايل زجاجي (Glass) بثلاث درجات (شفاف/ناعم/مصنّر) يعمل مع أي خلفية وفي الوضعين الداكن والفاتح.
- **درجات الجلاس** (من الإعدادات): شفاف بحافة مصنّرة خفيفة، مصنّر خفيف، أو مصنّر خالص — على طريقة Liquid Glass.
- **وضع توفير الذاكرة** (من الإعدادات): يوقف الحركات والخلفية المتحركة ويقلّص كاشات الأغلفة — مناسب لترك التطبيق مفتوحاً ساعات طويلة دون أن يغلقه النظام.
- **قوائم تشغيل**: إنشاء قوائم، إضافة أغانٍ، إزالة، وإعادة ترتيب بالسحب وبالأسهم.
- **تشغيل بالسياق**: يعرف يشتغل من «المكتبة الكاملة» أو من أي قائمة، ويستمر بعد إعادة فتح التطبيق بآخر أغنية وموضع.
- **عشوائي وتكرار**: تكرار الكل، تكرار الأغنية (بشارة)، وخلط ترتيب العرض دون كسر سياق القائمة.
- **شاشة تشغيل كاملة**: غلاف لكل أغنية، شريط تقدم قابل للسحب، صوت وكتم، وتخطيط لاندسكيب بعمودين.
- **تحكم النظام (MediaSession)**: أزرار سماعة البلوتوث/السيارة وشاشة القفل تعمل مباشرة، مع أسماء وأغلفة حقيقية.
- **تثبيت كتطبيق**: زر «تثبيت التطبيق» يفتح التثبيت كتطبيق مستقل (يشبه محلياً).
- **وضع تحديد**: تحديد أغانٍ متعددة لإضافتها لقائمة أو حذفها دفعة واحدة (مع تأكيد).
- **مظهرين**: داكن وأناري، ويتذكر اختيارك.
- لغة عربية RTL بالكامل، وحواف أنعم وأنيميشنز بين الشاشات والتشغيل.
- لا يطلب أي أذونات. لا إعلانات. لا تتبع.

## التشغيل محلياً

```bash
python dev/server.py 8090 .
```

ثم افتح `http://127.0.0.1:8090/` — بدون إعدادات إضافية.

> ملاحظة مهمة أثناء التطوير: استخدم `http://127.0.0.1:8090/?nosew` لتفعيل سلوك «بدون Service Worker» كي لا يخدم الكاش ملفات قديمة بعد تعديلات الكود.

## التثبيت من الرابط (جهازك الآخر)

1. افتح الرابط في Chrome (هاتف/تاب/حاسوب).
2. انقر زر **«تثبيت التطبيق»** أعلى الشاشة (أو أيقونة التثبيت في شريط العنوان).
3. يظهر التطبيق كأيقونة مستقلة يعمل بملء الشاشة وبلا شعارات متصفح.

## حفظ أغانيك

- أغانيك **تحفظ محلياً داخل المتصفح/التطبيق** على هذا الجهاز فقط.
- **مسح بيانات الموقع من إعدادات Chrome سيحذف جميع الأغاني نهائياً.**
- النقل بين الأجهزة: أعد إضافة الملفات (زر «إضافة أغانٍ») من كل جهاز — لا نرفع أي شيء.

## النشر

يُنشر على GitHub Pages من فرع `main` جذر المستودع (ملفات الجذر + مجلد `icons/`). بعد أول نشر، أي تعديل لاحق يعكسه المستخدمون عند إعادة التحميل عبر شريط «يوجد تحديث» وترقيم نسخة الـ `sw.js` (`VERSION = 'imusic-v1.1.5'`).

## الملفات

```
index.html            — هيكل التطبيق + أيقونات SVG + ورقة الإعدادات
styles.css            — التنسيق (داكن/نهاري، RTL، لاندسكيب، جلاس، خلفيات)
app.js                — كل المنطق (قاعدة بيانات، تشغيل، قوائم، أغلفة، خلفيات، تثبيت، تحديث)
sw.js                 — Service Worker (كاش أول، تحديث بالمزامنة)
manifest.webmanifest  — وصف التطبيق التثبيتي
icons/                — الأيقونات (SVG مصدر + PNG مولّدة)
dev/                  — أدوات تطوير (توليد أيقونات/أصوات/ملفات اختبار وسيرفر بلا كاش)
test-audio/           — ملفات صوت للتجربة (منها ملف تالف وملفات بصور مدمجة)
```

## أذونات وخصوصية

- التطبيق لا يطلب أي أذونات ولا يحتاج أي حسابات.
- البيانات كلها أيضًا: أغانيك بقاعدة IndexedDB، والإعدادات في `localStorage` (`imusic-prefs`).
